# Agents

The shared starting point for agent-assisted work at BinBop. This repository holds guidance that applies across business functions and repositories.

## Getting started

Start your coding agent from this directory and give it access to the repositories needed for the task. Codex can discover [AGENTS.md](AGENTS.md) here; other tools may need it supplied explicitly. The BinBop repositories normally sit alongside this one in the same parent directory. Starting here alone does not guarantee access to sibling repositories.

The `handbook` repository describes BinBop's product and working practices, including Ready, Set, Go. Each repository's README and CONTRIBUTING.md explain its own purpose and how to work there.
