# Contributing

Use [Ready, Set, Go!](https://github.com/BinBopHQ/handbook/blob/main/ready-set-go.md) to guide changes to shared guidance.

## Ready

What are we getting ready for? What guidance needs to change, who will use it, and what would finishing look like? Find the relevant existing instructions and decide where the information belongs.

**Are we ready?**

## Set

Are the relevant repositories and tools available? Is everything in place to make the change?

**Are we set?**

## Go!

Keep shared guidance concise, actionable, and applicable across BinBop. Put information specific to a repository with that repository unless it is needed to navigate the workspace. Avoid copying handbook content or introducing tools and processes without a clear need.

## Finish

*… and finish.*

Check that instructions match the actual setup, links resolve, and examples work. Consider how guidance applies to both technical and non-technical work.

Use clear, concise commit and pull request titles that describe the change, such as “Add a small-size logo.” Add context in the description when it helps. There is no required prefix format.

**Are we finished?**

## Shared guidance

The [handbook](https://github.com/BinBopHQ/handbook) contains BinBop's product and working practices.
