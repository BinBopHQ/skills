# Working at BinBop

This repository is a shared entry point for agent-assisted work across BinBop, including product, engineering, brand, and other business functions. Follow the user's instructions and the task's actual scope.

## Find the right context

- BinBop repositories are normally sibling directories of this one. Find the relevant repository and read its README and CONTRIBUTING.md when useful.
- Consult the `handbook` for shared product and working practices. Ready, Set, Go is a way to think about preparing for and doing work, not a requirement to add extra stages to every task.
- Check for applicable repository-specific instructions. Keep shared guidance here; repository-specific instructions belong in a local AGENTS.md only when needed.
- If a required repository or tool is unavailable, say what is missing. Access to this repository does not imply access to its siblings.

## Do the work

- Inspect existing work and preserve unrelated changes. Keep changes focused and remove temporary material you create when it is no longer needed.
- Use the repository's existing tools and conventions where appropriate. Check results with methods that fit the work; explain what was and was not verified.
- Use clear, concise descriptions for commits and pull requests. Follow any repository-specific contribution instructions.
- Put durable business decisions in the handbook and repository-specific work in the repository that owns it. Avoid duplicating guidance that has a clear home elsewhere.

## Repository template

For repository setup or maintenance, inspect the sibling `template` repository. Create new GitHub repositories from the BinBop template by default, then verify GitHub records the association. Customize starting files for the repository. When maintaining an existing repository, compare its practices with the template, adapt what fits, and preserve its own content. Do not imply that a repository was created from the template unless GitHub records that association. See `handbook/repository-practices.md` for the shared approach.
